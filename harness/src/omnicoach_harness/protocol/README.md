# Omni OTA V1 (`omni_ota_v1`)

The frozen Observe-Think-Action JSON actor protocol with explicit
temporal-interval grounding contracts:

- direct answer is legal on step 1;
- exact-one-decimal `MM:SS.m` tool boundaries and evidence citations;
- default 384-side focused frames and opt-in 1280-side high resolution;
- ordered, unnamed 2–8-span comparison in one model context;
- strict JSON-schema provider response mode and canonical flat actions;
- fixed 1/2 FPS focused sampling and compact provider-visible tool results;
- rich decoder/resource diagnostics retained only in persisted event info;
- one most-recent media-bearing message retained;
- TR answers must be one or more positive-width intervals, inside the video, with no surrounding prose;
- isolated points are recoverable invalid actions, never post-hoc padded;
- QA prompts and answers remain unchanged.

This package owns its prompt, parser, tools, limits, recovery messages, media
initialization, action identity, and stopping policy under route ID `omni_ota_v1`.
